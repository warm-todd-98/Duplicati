## About 📖

Duplicati is an open source backup solution maintained by the Duplicati team, built to protect local files by sending encrypted, versioned archives to destinations such as FTP, SFTP, WebDAV, S3 compatible storage, Backblaze B2, Google Drive, OneDrive, Dropbox and other supported backends. It schedules automatic runs, keeps multiple restore points, supports strong AES encryption and can verify backup integrity after each run. The 2026 build refreshes the Web UI, improves database handling on large backup sets and updates the bundled backend libraries.

If you came looking for a Duplicati download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Setup is straightforward: grab the installer, run it, and configure your backup destination from the browser interface.

**Good for:** home users backing up personal documents · small offices protecting shared folders · users archiving to cloud storage · anyone needing encrypted offsite copies · people scheduling automatic nightly jobs · technicians restoring from versioned snapshots · Windows users moving data between drives and remote targets.

## Troubleshooting 🛠️

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without finishing | Restart Windows, then run the setup file again as administrator. |
| Browser UI does not open after launch | Check that port 8200 is not used by another app, then restart Duplicati. |
| Backup job fails on connection test | Recheck credentials, host, port and path for the chosen destination. |
| Very slow first backup | The initial run uploads everything, expect longer times and let it finish. |
| Restore shows missing versions | Confirm the backup job completed and the destination was not cleared. |
| Antivirus flags a downloaded archive | Whitelist the Duplicati working folder in your security software settings. |
